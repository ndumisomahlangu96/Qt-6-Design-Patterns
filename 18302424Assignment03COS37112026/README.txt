# Execution Guide: Assignment Programs

To ensure all programs in this folder run correctly, please follow the specific execution order outlined below. 

The programs in this directory (`Question02`, `Question03`, and `Question04`) depend on an executable file that is generated by the first program (`Question01GetStudentInfo`). If the first program is not compiled and executed beforehand, the subsequent programs will fail to run.

## Step-by-Step Execution Instructions

**Step 1: Compile and Run Question 1 First**
You must begin by running `Question01GetStudentInfo`. 
* Compiling and executing this program will automatically generate the required executable file named `Question01.GetStudentInfo.exe`.
* Wait for this program to finish running completely before moving on to the next step.

**Step 2: Verify the Executable**
Ensure that `Question01.GetStudentInfo.exe` has been successfully created and is located in the correct directory. This file acts as a core dependency for the remaining questions.

**Step 3: Run the Remaining Programs**
Once the executable from Step 1 is in place, you can safely compile and run the rest of the programs in any order:
* `Question02`
* `Question03`
* `Question04`

## Troubleshooting
If you encounter a "Process Error: QProcess::FailedToStart" or "Error: Question01GetStudentInfo.exe could not be found in subdirectories." when trying to run Questions 02, 03, or 04, it means the required `.exe` file is missing. Please go back to Step 1, rebuild `Question01GetStudentInfo`, and ensure the output executable is placed in the build folder where the other programs can access it.
